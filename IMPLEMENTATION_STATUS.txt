All three pages now use: MANDATORY SKILLS ONLY

Scoring Formula:
  Match % = (Earned mandatory weight / Total mandatory weight) × 100

Per-Skill Scoring:
  • Full Match  (years ≥ required)     → 100% weight
  • Good Match  (years ≥ 80% required) → 70% weight
  • Partial     (years < 80% required) → (ratio × 50%) weight
  • Missing     (no experience)        → 0% weight
